# M5 AI 因果解读实现计划 (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 构建可插拔的 AI 解读层：对最热话题/事件生成**因果链与解读**，provider 抽象支持**火山方舟 ARK**（OpenAI 兼容）与 **Mock**（测试/离线兜底），暴露 `insights:generate` IPC。

**Architecture:** `AiProvider` 接口定义 `generate(messages): Promise<string>`；`ArkProvider` 走 ARK 的 OpenAI 兼容 REST（伪码：`POST {base}/chat/completions`、`Authorization: Bearer <ARK_API_KEY>`、`model`=ARK_MODEL 或 `ep-*`）；`MockProvider` 供测试与无 Key 时兜底。`interpreter` 负责「拼 prompt → 调 provider → 解析为 Insight」。工厂 `createProvider()` 依环境变量选型。

**Tech Stack:** Electron main (Node/TS), `axios`。

**Spec:** `docs/superpowers/specs/2026-09-14-lumen-world-trends-design.md`

## Global Constraints
- 唯一类型来源：`shared/insight.ts`。
- `AiProvider` 仅依赖 `messages`（OpenAI 兼容 messages 数组），输出纯文本；解析在 interpreter 内完成。
- `createProvider()`：`ARK_API_KEY` 存在 → `ArkProvider`；否则 `MockProvider`。
- ARK 默认环境变量：`ARK_API_KEY`（必选）、`ARK_BASE_URL`（默认 `https://ark.cn-beijing.volces.com/api/v3`）、`ARK_MODEL`（模型 id 或 `ep-*`，默认 `doubao-seed-1-6-250615`）。如设 `ARK_MODEL` 以 `ep-` 开头，则视为端点上则直接传 `model=ARK_MODEL`。
- 不含真实网络调用的测试全部走 MockProvider 或 request 构造纯函数。

`arkChatRequest`：
```ts
export function arkChatRequest(cfg: ArkConfig, messages: ChatMessage[]): { url: string; headers: Record<string, string>; body: string } {
  return {
    url: `${cfg.baseUrl.replace(/\/$/, '')}/chat/completions`,
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${cfg.apiKey}`
    },
    body: JSON.stringify({ model: cfg.model, messages, stream: false })
  };
}
```

`ArkProvider.generate` 用 `axios.post(arkChatRequest(...))`，解析 `data.choices[0].message.content`。
`MockProvider.generate` 返回 `'（离线 mock）…提供了对输入话题的概括解读…'`。
`createProvider(env)`：`env.ARK_API_KEY` → `ArkProvider(env.ARK_BASE_URL ?? ARK_DEFAULT_BASE, env.ARK_API_KEY, env.ARK_MODEL ?? ARK_DEFAULT_MODEL)`；否则 `MockProvider`。

## Rulings（裁定记录）
- **Ruling 11 — provider 依环境变量选型，默认 mock**：当前环境无 ARK Key，先打通可插拔工程；设 `ARK_API_KEY` 即切真 ARK，不影响采集/图谱/趋势离线。
- **Ruling 12 — 解读用 OpenAI 兼容 /chat/completions**：ARK 支持该兼容协议，`Authorization: Bearer <key>`、`model` 可为模型 id 或 `ep-*`。若 ARK 该端点变更，按 RequestError 调整 provider。
- **Ruling 13 — 单次解读聚焦最热话题（top 8 + 国家）**：控制在 400 字内保证响应稳定；更长周报样式留给看板/后续。
